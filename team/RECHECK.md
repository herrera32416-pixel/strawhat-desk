# RECHECK SOP (pre-kick, driven by kickoff times)
**When:** crons at :15 and :45 (Sat/Sun 15–22 UTC, Sun 12–14 UTC for London games, every day 23–03 UTC for night games). Each cron first runs the free planner `python3 -m desk.recheck_plan`, and the job only continues on `go=yes`: an unstarted item (board PICK, PLAY teaser keyed by its first leg's kick, or logged prop) kicks within **70 min** and its kickoff window hasn't been rechecked today (`data/recheck_done.json`). On a normal Sunday this fires ~11:15am CT (noon kicks), ~2:15pm (3:05/3:25) and ~6:15pm (7:20). The other crons are backups that no-op. Manual: `gh workflow run daily.yml -f mode=recheck`.
1. Re-pull `/odds` (us+eu, spreads+totals) only for the games of open official items in the window, filtered by `eventIds`: **4 credits** per window, at most 3 windows/day, through the 40/day cap. The 9am run reserves these (`recheck.reserve_credits`). Prop-only windows cost 0 credits.
2. Board: same side's best DK/Bovada price now. DROP if EV < 3%, the line moved strictly through a key number (NFL spread ±3/7/10/14; CFB spread ±3/7/10/14/17/21; NFL total 37/41/44/47/51), or |fair − book line| > 3 pts. Otherwise KEPT. No new picks.
3. Teasers/parlays: retired 2026-10-08; none are produced, so none are rechecked.
4. Props: free ESPN injury report; a player now Out/IR/inactive gets VOID.
5. Ledger: matching items get VOID with the reason; the original stamp is kept. Every pass is kept in `docs/data/recheck.json` and shown on the Board tab. `python -m desk.recheck --dry` prints the plan without spending.
