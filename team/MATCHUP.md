# MATCHUP SOP (NFL, INFO ONLY)
**Purpose:** compare each team's offensive and defensive units with this week's opponent's, explain the clear mismatches in plain English, and test honestly whether that adds anything to the market line.

**Data (free, 0 Odds API credits):** nflverse play-by-play 2015–2026 → `desk/matchup_data.py` → `data/matchup/team_games.csv.gz` (one row per team-game: dropback EPA/SR, designed-run EPA/SR, sack rate, pressure proxy = sack or QB hit per dropback (nflverse has no charted pressures before 2022), neutral early-down pass rate, explosive-play rate (pass ≥ 20, run ≥ 10), red-zone TD rate). The daily run re-downloads only the current season.

**Ratings (`desk/matchup.py`):** for each game date, weighted ridge on games strictly before that date: metric = μ + O[offense] + D[defense] + home. Current season weight 1, last season 0.35, penalty 6 full-weight games. Units: pass offense/defense (EPA per dropback), run offense/defense (EPA per designed run), pass protection vs pass rush (pressure rate), explosives, red zone.

**Matchup features (home minus away):** expected pass EPA, run EPA, sack and pressure rate, explosive rate and red-zone TD rate (offense rating + opposing defense rating), plus interactions (z offense × z opposing defense for pass, run and protection: "elite rush vs weak OL"). **Style similarity:** style vector = early-down pass rate, pass-vs-run efficiency, explosiveness, OL sack exposure, defense pass-funnel vs run-funnel, sack generation, explosives allowed. For each matchup, each team's past cover margins vs opponents with a style like this week's foe (Gaussian kernel, τ = 0.6, the same opponent counts fully, shrunk with 3 pseudo-games). **Common opponents:** each team's average cover margin vs teams both have played (this season + last), difference shrunk by 3. Style quadrant labels (pass-first/run-first × pass-funnel/run-funnel D) are shown on the site.

**Test (`backtest/matchup_bt.py`, pre-registered):** target = residual vs the closing line (result − spread_line; total − total_line). Ridge on standardized features, no intercept, λ chosen by leave-one-season-out CV inside the training seasons; train on seasons < s, test on s (2018–2026). Model p = de-vigged closing p + KEYS shift for the lean. **Criteria to influence picks** (spread or total, pooled OOS 2018–25): (1) log-loss improvement with 90% CI > 0, (2) |lean| ≥ 1.5 bets at −110 with win% 90% CI lower bound > 52.38%, (3) positive units in ≥ 6 of 8 seasons. All three are needed.

**Result (2026-10-04): fails all three → INFO ONLY.** Spread, 2,175 games: log loss 0.6926 vs market 0.6925 (improvement CI −0.0005…+0.0004). CV always picks the largest penalty (leans ~0.1 pt; no bet ever reaches 1 pt). Total, 2,205 games: 0.6933 vs 0.6931. Sensitivity with light shrinkage (λ = 30, not used for the decision): ATS |lean| ≥ 1.5: 188-197 (48.8%), −26.1u; O/U 301-306, −32.4u; positive in 2–3 of 8 seasons. The closing line already prices these unit matchups.

**Live:** `desk/run.py` → `matchup.live()` → `docs/data/matchups.json` → site **Matchups** tab (unit ranks, edges, style labels, similar-foe and common-opponent numbers, the model lean marked "info only", and the backtest line). `data/matchup/model.json` holds the live model and `influence=false`; the board never reads it. Turning on influence would need the criteria to pass on a re-run and a code change reviewed by Luis.

**CFB (added 2026-10-04, `desk/matchup_cfb.py`):** free cfbfastR play-by-play (sportsdataverse-data releases, 2021–26) → `data/matchup/cfb_team_games.csv.gz`, joined to the desk's ESPN closes by ESPN game id. Same units, features and walk-forward method, with stronger shrinkage (ridge penalty 12 games). FCS opponents are rated for connectivity, but ranks are among FBS teams only. There is no pressure/QB-hit data, so pass rush vs protection uses sack rate. Live lines come from the ESPN scoreboard (DraftKings), which is free.
- Pre-registered CFB criteria (`backtest/matchup_cfb_bt.py`): pooled OOS 2024–25, the same (1) and (2) as NFL, and (3) units positive in both seasons.
- **Result: fails → INFO ONLY.**
  - Spread, 1,788 games: log loss 0.6939 vs market 0.6936 (CI −0.0008…+0.0002). CV picks the largest penalty (leans ~0.25 pt).
  - Total, 1,786 games: 0.6927 vs 0.6932 (CI −0.0001…+0.0011); no bets reach 1.5 pts.
  - Sensitivity, not used for the decision: the lightly-shrunk spread went 303-310, −34.5u. The lightly-shrunk CFB *total* went 166-131 (55.9%, CI 51.2–60.6%), +19.9u, positive in both seasons. That is one cell out of roughly a dozen sensitivity cells, and it wasn't pre-registered, so it is a **watch item** to re-test on 2026 data, not a signal.
